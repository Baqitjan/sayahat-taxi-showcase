## 🌟 Key Architecture & Capabilities

### 1. Passenger Module
* **Real-time Map:** Interactive location selector using OpenStreetMap (avoids excessive Google Maps API costs).
* **Order Flow:** Destination search, dynamic fare estimation, and driver bidding logic.
* **Support:** In-app 24/7 support messaging system.

### 2. Driver Module
* **Work Modes:** Quick Online/Offline availability toggle.
* **Order Feed:** Live broadcast of incoming ride requests with pickup/drop-off points.
* **Driver Balance & Wallet:** Real-time earnings tracker, transaction history, and balance top-up flow.
* **Background Tracking:** Location synchronization for navigation and trip execution.

### 3. Backend & Administration
* **Supabase / PostgreSQL:** Optimized database tables, triggers, and Row-Level Security policies.
* **Scalability:** Easily handles 5,000–10,000 active concurrent users on cost-effective infrastructure.
* **Web Admin Panel:** Full management of registered drivers, ongoing rides, tariffs, and revenue metrics.
